1. Bẫy Scoping: Khai báo Hàm trong Block Scope (Annex B)

JavaScript — Đoạn mã phỏng vấn kinh điển 
var a = 1;
function test() {
  a = 10;
  return;
  function a() {}
}
test();
console.log(a); // Kết quả in ra là gì?
💡 Giải mã chuẩn ECMA-262

Hàm function a() {} được hoist lên đầu phạm vi của hàm test(). Do đó, bên trong test() tồn tại một biến cục bộ tên là a. Lệnh a = 10 thực chất gán lại giá trị cho biến cục bộ này mà không chạm tới biến var a = 1 ở phạm vi toàn cục. Kết quả in ra 1.

2. Bẫy Mảng thưa (Sparse Arrays) & Array Holes

JavaScript — Array Holes vs Iterator Methods 
const arr = [1, 2, , 4]; // arr[2] là hole (empty)
const result = arr.map(x => x * 2);

console.log(result);         // [2, 4, <1 empty item>, 8]
console.log(2 in result);     // false (index 2 không tồn tại thuộc tính)
console.log(Object.keys(arr)); // ["0", "1", "3"] (Bỏ qua hole hoàn toàn)

4. Ma trận ưu tiên ép kiểu ngầm định: Symbol.toPrimitive

JavaScript — Custom ToPrimitive Implementation 
const item = {
  valueOf() { return 10; },
  toString() { return '20'; },
  [Symbol.toPrimitive](hint) {
    if (hint === 'number') return 100;
    if (hint === 'string') return 'Antigravity';
    return 50; // hint === 'default'
  }
};

console.log(item + 10);   // 60  (Gọi ToPrimitive với hint "default")
console.log(+item);       // 100 (Gọi ToPrimitive với hint "number")
console.log(`${item}!`);  // "Antigravity!" (Gọi ToPrimitive với hint "string")
