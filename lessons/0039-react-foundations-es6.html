1. Bóc tách Props: Giá trị mặc định, Đổi tên & Rest Props

Trong React Component, destructuring giúp code tường minh và dễ đọc hơn rất nhiều so với việc lặp lại props.something:

JavaScript — Clean Props Destructuring Pattern 
function Button({
  title = 'Submit',               // 1. Default Value khi prop bị undefined
  variant: btnVariant = 'primary', // 2. Aliasing (đổi tên biến để tránh trùng lặp)
  onClick,
  ...restProps                     // 3. Rest Parameters gom tất cả props còn lại (aria-*, id, style...)
}) {
  return (
    <button className={`btn btn-${btnVariant}`} onClick={onClick} {...restProps}>
      {title}
    </button>
  );
}

2. Quản lý State bất biến (Immutability) với Spread Operator (...)

React phụ thuộc vào Shallow Comparison (Object.is) để quyết định re-render. Việc đột biến trực tiếp object (Mutation) sẽ khiến React bỏ qua re-render hoặc sinh ra bug không thể dự đoán:

JavaScript — ĐÚNG vs SAI khi cập nhật Nested State 
// ❌ SAI HOÀN TOÀN: Trực tiếp mutate state cũ
// prevState.user.profile.theme = 'dark'; setState(prevState); // React KHÔNG re-render!

// ✅ ĐÚNG CHUẨN REACT: Tạo shallow copy tại từng tầng có sự thay đổi
setState(prev => ({
  ...prev,
  user: {
    ...prev.user,
    profile: {
      ...prev.user.profile,
      theme: 'dark'
    }
  }
}));

3. Xử lý Form động với Computed Property Names [name]: value

Thay vì viết 10 hàm handleNameChange, handleEmailChange..., bạn chỉ cần 1 hàm duy nhất xử lý toàn bộ form:

JavaScript — Unified Form Change Handler 
const [formData, setFormData] = useState({ username: '', email: '', subscribe: false });

function handleChange(e) {
  const { name, value, type, checked } = e.target;
  setFormData(prev => ({
    ...prev,
    [name]: type === 'checkbox' ? checked : value // Computed property name
  }));
}

4. Bẫy giao diện: Nullish Coalescing (??) vs Logical OR (||)

Toán tửĐiều kiện kích hoạt FallbackHành vi với số 0, chuỗi rỗng "", false
Logical OR (||) Bất kỳ giá trị Falsy nào (null, undefined, 0, false, "", NaN). BỊ GHI ĐÈ: 0 || 10 trả về 10. Khiến giỏ hàng có 0 sản phẩm hiển thị thành 10!
Nullish Coalescing (??) Chỉ kích hoạt khi giá trị là null hoặc undefined (Nullish). BẢO TOÀN: 0 ?? 10 trả về đúng 0. Đây là toán tử bắt buộc dùng khi render UI counts!
