2. 4 Trụ cột tư duy JavaScript → React Senior

1. Shallow Reference & Object.is

React chỉ kích hoạt re-render khi tham chiếu thay đổi. Việc mutate trực tiếp object/array sẽ bị React bỏ qua do Object.is(prev, next) === true.

2. ES2023 Non-mutating Methods

  • toSorted() thay cho sort()
  • toReversed() thay cho reverse()
  • toSpliced() thay cho splice()
  • with(index, val) thay cho arr[i] = val

3. Bẫy Fetch Error Handling

fetch() không tự reject trên HTTP 404/500! Luôn kiểm tra if (!res.ok) throw new Error(...) và bỏ qua AbortError trong khối catch.

4. Derived State over Extra State

Không tạo thêm useState cho các giá trị có thể tính toán trực tiếp từ Props/State hiện tại bằng reduce, filter hoặc map.
