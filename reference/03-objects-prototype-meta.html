1. Trục 1: Prototype Chain (Bài 09)

Khái niệm Bản chất kỹ thuật (ECMAScript) Vị trí tồn tại & Lưu ý Senior
[[Prototype]] Internal slot ẩn trỏ tới prototype object cha mà đối tượng kế thừa. Đỉnh chuỗi là Object.prototype có [[Prototype]] === null. Có trên mọi object (trừ Object.create(null)). Truy cập chuẩn bằng Object.getPrototypeOf().
__proto__ Accessor property (getter/setter) trên Object.prototype. Đã bị coi là deprecated; tránh dùng trong production.
prototype Thuộc tính object thông thường làm khuôn mẫu cho các instance. Chỉ có trên Function Constructor và Class. Arrow Functions và plain object instance KHÔNG CÓ.
Property Shadowing Gán thuộc tính lên con tạo Own Property che khuất thuộc tính cùng tên của prototype cha mà không làm thay đổi cha. Kiểm tra thuộc tính riêng bằng Object.hasOwn(obj, prop).

2. Trục 2: Toán tử `new` & `Object.create()` (Bài 10)

4 BƯỚC TOÁN TỬ NEW

Internal Method [[Construct]]

1. Cấp phát object rỗng: const instance = {}.

2. Nối prototype: instance.[[Prototype]] = Constructor.prototype.

3. Gán ngữ cảnh this và thực thi: Constructor.apply(instance, args).

4. The Return Trap: Nếu hàm trả về Object/Function → Trả về Object đó; nếu trả về Primitive (kể cả null) → Trả về instance.

OBJECT.CREATE VS NEW.TARGET

Khởi tạo đối tượng nâng cao

Object.create(proto): Thiết lập liên kết prototype trực tiếp mà không cần thực thi hàm khởi tạo.

new.target: Meta-property phát hiện hàm có được gọi bằng new hay không. Nền tảng của Safe Constructor Pattern tự động kích hoạt new.

3. Trục 3: ES6 Classes vs Prototypal Inheritance (Bài 11)

Tính năng Bản chất cơ chế tầng Engine Quy tắc bắt buộc & Ứng dụng
ES6 Class 100% là Syntactic Sugar trên Prototype Chain. Bắt buộc gọi bằng new (ném TypeError nếu thiếu), tự động Strict Mode, dính TDZ trong Creation Phase.
Bí mật super() Trong Subclass (extends), Base Class chịu trách nhiệm khởi tạo ô nhớ cho this. Bắt buộc gọi super() trước khi truy cập this, vi phạm sẽ ném ReferenceError.
Kế thừa kép Thiết lập 2 chuỗi prototype song song: Instance chain (Child.prototype → Parent.prototype) và Static chain (Child → Parent). Cho phép các phương thức tĩnh (static methods) được kế thừa trực tiếp giữa các class.
Private Fields (#field) Tính năng ES2022 được Engine kiểm soát ở tầng bytecode qua cơ chế PrivateBrand. Bảo mật cấp ngôn ngữ (Hard Private): ném SyntaxError nếu truy xuất ngoài class, vô hình trước reflection.

4. Trục 4: Meta-programming, Proxy & Reactivity (Bài 12)

Thành phần Nguyên lý hoạt động Ưu thế vượt trội
Proxy API Bọc quanh target object và đánh chặn 13 internal methods (get, set, has, deleteProperty, apply...). Khắc phục toàn bộ nhược điểm của Object.defineProperty: nhận diện thêm/xóa key tự động, hỗ trợ mảng native, Lazy evaluation.
Reflect API Bộ 13 phương thức chuẩn tĩnh ánh xạ 1:1 với Proxy Traps. Tham số receiver trong Reflect.get(target, prop, receiver) bảo toàn context this cho các getter kế thừa, ngăn chặn bug mất reactivity.
Reactivity Engine Mô hình cốt lõi của Vue 3: track(target, key) ghi nhận dependency khi get, trigger(target, key) kích hoạt lại effect khi set. Nền tảng của kiến trúc Reactive State và Signals hiện đại.
