1. Bẫy số 0 kinh điển trong toán tử && (Short-circuiting)

Trong JavaScript, toán tử a && b trả về giá trị của vế trái nếu vế trái là Falsy. Do đó, khi messages.length === 0, biểu thức 0 && <Badge /> trả về đúng số 0:

JavaScript — Cạm bẫy số 0 trên giao diện React 
function NotificationBar({ messages = [] }) {
  return (
    <div>
      <h3>Hộp thư đến</h3>
      {/* ❌ SAI: Khi messages = [], màn hình sẽ hiện một số '0' trơ trọi! */}
      {messages.length && <span className="badge">{messages.length}</span>}

      {/* ✅ CÁCH 1: So sánh lớn hơn 0 tường minh */}
      {messages.length > 0 && <span className="badge">{messages.length}</span>}

      {/* ✅ CÁCH 2: Ép kiểu Boolean sạch */}
      {Boolean(messages.length) && <span className="badge">{messages.length}</span>}

      {/* ✅ CÁCH 3: Dùng toán tử 3 ngôi (Ternary) */}
      {messages.length > 0 ? <span className="badge">{messages.length}</span> : null}
    </div>
  );
}

3. Kỹ thuật Early Return (Guard Clauses) trong Component

Thay vì lồng 4 tầng ternary bên trong khối JSX, hãy xử lý các trạng thái đặc biệt ở đầu hàm component:

JavaScript — Early Return Clean Pattern 
function ProductList({ loading, error, products }) {
  // 1. Xử lý trạng thái Loading
  if (loading) return <div className="spinner">Đang tải dữ liệu...</div>;

  // 2. Xử lý trạng thái Lỗi
  if (error) return <div className="alert error">Đã xảy ra lỗi: {error}</div>;

  // 3. Xử lý trạng thái Trống (Empty State)
  if (!products || products.length === 0) {
    return <div className="empty">Không có sản phẩm nào phù hợp.</div>;
  }

  // 4. Luồng chính (Happy Path): Rất sạch sẽ và không bị lồng ghép!
  return (
    <ul className="grid">
      {products.map(p => <li key={p.id}>{p.name}</li>)}
    </ul>
  );
}

4. Pattern Dictionary Mapping cho đa điều kiện

Khi có 3 trạng thái trở lên (Pending, Approved, Rejected, Canceled...), thay vì viết status === 'pending' ? ... : status === 'approved' ? ..., hãy dùng một Object Lookup:

JavaScript — Dictionary Lookup Pattern 
const STATUS_CONFIG = {
  pending: { label: 'Đang chờ', className: 'badge-warning' },
  approved: { label: 'Đã duyệt', className: 'badge-success' },
  rejected: { label: 'Từ chối', className: 'badge-danger' }
};

function StatusBadge({ status }) {
  const config = STATUS_CONFIG[status] ?? { label: 'Không rõ', className: 'badge-muted' };
  return <span className={`badge ${config.className}`}>{config.label}</span>;
}
