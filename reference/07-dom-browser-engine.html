1. Bảng quy chuẩn 6 bước Critical Rendering Path

Giai đoạnĐầu vàoĐầu raTác động hiệu năng
1. DOM Tree HTML Bytes / Tokens Cây cấu trúc DOM Bị chặn bởi Synchronous <script> (khắc phục bằng defer)
2. CSSOM Tree CSS Rules / Stylesheets Cây luật CSSOM Render-Blocking: Chặn render điểm ảnh để chống FOUC
3. Render Tree DOM + CSSOM Cây hiển thị (Visual Tree) Loại bỏ display: none; giữ lại visibility: hidden / opacity: 0
4. Layout (Reflow) Render Tree Nodes Tọa độ hình học $(x, y, w, h)$ Chạy trên CPU Main Thread, chi phí tính toán cao nhất khi DOM thay đổi
5. Paint (Repaint) Layout Boxes Bitmap điểm ảnh (Colors/Borders) Vẽ các thành phần trực quan lên từng Layers
6. Composite Layers Màn hình hiển thị GPU Thread (60fps mượt mà cho transform, opacity)

2. Ma trận DOM Event Flow & Forced Reflow APIs

W3C DOM Event Flow

1. Capturing (true) : Window → Document → Parent → Target.

2. Target : Tại chính phần tử event.target.

3. Bubbling (false - mặc định) : Nổi ngược từ Target → Window.

stopPropagation(): Chặn nổi bọt nhưng các listener khác trên cùng node vẫn chạy.

stopImmediatePropagation(): Chặn nổi bọt VÀ chặn luôn mọi listener còn lại.

{ passive: true }: Cam kết không gọi preventDefault() → cuộn mượt 60fps.

Danh sách API gây Forced Reflow

Kích thước : offsetWidth, offsetHeight, clientWidth, clientHeight.

Vị trí : offsetTop, offsetLeft, clientTop, clientLeft.

Cuộn : scrollTop, scrollLeft, scrollWidth, scrollHeight.

Đo đạc : getBoundingClientRect(), getComputedStyle().

Quy tắc vàng FastDOM : Đọc tất cả trước → Ghi tất cả sau !

3. Service Worker: Bộ 3 Caching Strategies chuẩn PWA

JavaScript — Caching Strategies Cheatsheet 
// 1. Cache-First: Asset tĩnh (JS, CSS, Images, Fonts)
const cacheFirst = async (req, cacheName) => {
  const cached = await caches.match(req);
  if (cached) return cached;
  const res = await fetch(req);
  const cache = await caches.open(cacheName);
  cache.put(req, res.clone());
  return res;
};

// 2. Network-First: Dữ liệu động (API feeds, tin tức mới nhất)
const networkFirst = async (req, cacheName) => {
  try {
    const res = await fetch(req);
    const cache = await caches.open(cacheName);
    cache.put(req, res.clone());
    return res;
  } catch {
    return caches.match(req); // Fallback khi mất mạng
  }
};

// 3. Stale-While-Revalidate: Trả cache 0ms & fetch cập nhật ngầm
const staleWhileRevalidate = async (req, cacheName) => {
  const cached = await caches.match(req);
  const update = fetch(req).then(async (res) => {
    const cache = await caches.open(cacheName);
    cache.put(req, res.clone());
    return res;
  });
  return cached || update;
};
