1. Ma trận so sánh toàn diện: CommonJS (CJS) vs ECMAScript Modules (ESM)

Tiêu chí so sánhCommonJS (CJS)ECMAScript Modules (ESM)
Chuẩn hóa Cộng đồng Node.js (2009) Chuẩn chính thức ECMA-262 (ES2015+)
Thời điểm nạp (Loading) Runtime & Synchronous (Chặn luồng khi nạp file) Asynchronous & Static 3-Phase (Construction, Instantiation, Evaluation)
Cơ chế Binding Value Copy (Sao chép giá trị tại thời điểm export) Live Bindings (Trỏ trực tiếp vào Module Environment Record)
Tree-Shaking Rất khó hoặc không thể (do cấu trúc động runtime) Tối ưu hoàn hảo (phân tích tĩnh tại compile-time)
Top-level await Không hỗ trợ trực tiếp (phải bọc trong async IIFE) Hỗ trợ chuẩn (ES2022+), tạm dừng module graph con
Phạm vi biến (Scope) Bọc trong Module Wrapper IIFE (có __dirname, __filename) Module Scope riêng biệt (dùng import.meta.url)
Circular Dependencies Trả về Partial Exports (dễ bị undefined) Wire-up trước; hàm chạy an toàn, biến rơi vào TDZ

2. 4 Trụ cột kiến thức Module Systems chuẩn Senior

1. CJS Module Wrapper & Cache

Node.js bọc code trong hàm:

(function (exports, require, module, __filename, __dirname) { ... })

Kết quả trả về được lưu vào require.cache. Các lần nạp sau chỉ trả về cache.

2. ESM 3-Phase Lifecycle

  1. Construction: Tải và Parse thành Module Records (Static Analysis).
  2. Instantiation: Cấp phát vùng nhớ & tạo Live Bindings.
  3. Evaluation: Chạy mã từ lá lên gốc (Top-level await).

3. Bẫy Circular Dependencies

CJS: Module nhận partial exports chưa gán → crash do undefined.
ESM: Hàm (hoisted) gọi an toàn; biến const/let bị lỗi TDZ (ReferenceError).

4. Dual Package Hazard

Xuất bản 2 bản build (CJS + ESM) khiến singleton bị nhân đôi.
Giải pháp: Dùng conditional exports trong package.json và cờ __esModule interop.

3. Checklist năng lực chuẩn phỏng vấn — Module 09

✅ Phân tích được sự khác biệt giữa Static Analysis (ESM) và Dynamic Loading (CJS).
✅ Giải thích tại sao ESM hỗ trợ Tree-shaking còn CJS thì không.
✅ Tường thuật chi tiết cơ chế Live Bindings và vẽ sơ đồ phân bổ bộ nhớ.
✅ Khắc phục lỗi Circular Dependencies và cấu hình thư viện npm chống Dual Package Hazard.
