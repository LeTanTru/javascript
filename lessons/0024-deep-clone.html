1. Các phương pháp Clone và Cạm bẫy của JSON.stringify

Phương phápĐộ sâuHạn chế / Bẫy chết người
Spread {...obj} / Object.assign Shallow (1 cấp) Các object con bên trong vẫn giữ nguyên địa chỉ tham chiếu vùng nhớ cũ.
JSON.parse(JSON.stringify(obj)) Deep ❌ Mất undefined, Symbol, Function.
❌ Biến Date thành string ISO, biến RegExp/Map/Set thành object rỗng {}.
❌ Crash ngay lập tức nếu có Circular Reference (TypeError: Converting circular structure to JSON).
structuredClone(obj) (HTML5 Standard) Deep ✅ Tích hợp sẵn trong Browser & Node.js 17+, hỗ trợ Circular Ref, Date, Map, Set.
❌ Ném lỗi DataCloneError nếu object chứa Function, Symbol, hoặc DOM Node.
Custom deepClone (Polyfill) Deep Kiểm soát 100% logic, tùy biến xử lý Function, Symbol và giữ nguyên prototype chain.

2. Giải quyết Tham chiếu vòng (Circular References) bằng WeakMap

Giả sử bạn có object parent.child = child; child.parent = parent;. Nếu đệ quy thông thường, hàm sẽ gọi đệ quy vô tận và ném lỗi RangeError: Maximum call stack size exceeded.

💡 Tại sao dùng WeakMap thay vì Map ?

WeakMap chỉ giữ tham chiếu yếu (weak reference) đến các object khóa. Khi quá trình clone kết thúc, bảng tra cứu này sẽ được Garbage Collector tự động dọn dẹp khỏi bộ nhớ, tránh memory leak khi clone các cây dữ liệu khổng lồ.

3. Live-coding: Cài đặt deepClone() chuẩn Senior

JavaScript — Custom deepClone polyfill 
function deepClone(value, hash = new WeakMap()) {
  // 1. Primitives, Function hoặc null -> trả về trực tiếp
  if (value === null || typeof value !== 'object') {
    return value;
  }

  // 2. Xử lý Date & RegExp
  if (value instanceof Date) return new Date(value.getTime());
  if (value instanceof RegExp) return new RegExp(value.source, value.flags);

  // 3. Xử lý Circular References (Tham chiếu vòng)
  if (hash.has(value)) {
    return hash.get(value);
  }

  // 4. Xử lý Map
  if (value instanceof Map) {
    const clonedMap = new Map();
    hash.set(value, clonedMap);
    value.forEach((v, k) => {
      clonedMap.set(deepClone(k, hash), deepClone(v, hash));
    });
    return clonedMap;
  }

  // 5. Xử lý Set
  if (value instanceof Set) {
    const clonedSet = new Set();
    hash.set(value, clonedSet);
    value.forEach((v) => {
      clonedSet.add(deepClone(v, hash));
    });
    return clonedSet;
  }

  // 6. Khởi tạo mảng hoặc object giữ nguyên Prototype Chain
  const isArray = Array.isArray(value);
  const result = isArray ? [] : Object.create(Object.getPrototypeOf(value));
  hash.set(value, result);

  // 7. Duyệt toàn bộ keys (kể cả Symbol) bằng Reflect.ownKeys
  const keys = Reflect.ownKeys(value);
  for (const key of keys) {
    const descriptor = Object.getOwnPropertyDescriptor(value, key);
    if (descriptor && descriptor.enumerable) {
      result[key] = deepClone(value[key], hash);
    }
  }

  return result;
}
