1. Memoization là gì & Điều kiện áp dụng

Memoization là kỹ thuật tối ưu hóa lưu lại (cache) kết quả trả về của các hàm dựa trên tập tham số đầu vào. Khi hàm được gọi lại với cùng tham số, kết quả được lấy ngay từ bộ nhớ đệm mà không cần tính toán lại.

⚠ Chỉ Memoize Pure Functions !

Nếu bạn memoize một Impure Function (hàm phụ thuộc thời gian Date.now(), dữ liệu ngoài hoặc gọi HTTP ngẫu nhiên), các lần gọi sau sẽ trả về dữ liệu cũ đã bị stale (lỗi thời) mà không phản ánh đúng trạng thái mới của hệ thống.

JavaScript — Cài đặt memoize() chuẩn Lodash 
function memoize(fn, resolver) {
  if (typeof fn !== 'function') throw new TypeError('Expected a function');

  const memoized = function (...args) {
    // Tạo cache key từ resolver tùy biến hoặc JSON.stringify mặc định
    const key = typeof resolver === 'function' 
      ? resolver.apply(this, args) 
      : JSON.stringify(args);

    const cache = memoized.cache;
    if (cache.has(key)) {
      return cache.get(key); // Trả về kết quả từ Cache
    }

    const result = fn.apply(this, args);
    cache.set(key, result);  // Lưu vào Cache
    return result;
  };

  memoized.cache = new Map(); // Expose cache để cho phép clear / delete
  return memoized;
}

2. LRU Cache (Least Recently Used) & Độ phức tạp O(1)

Nếu chỉ dùng Map để cache vô hạn, dung lượng RAM sẽ tăng mãi và gây tràn bộ nhớ (Memory Leak). LRU Cache giới hạn dung lượng tối đa capacity. Khi bộ đệm đầy, nó sẽ loại bỏ phần tử ít được sử dụng nhất (Least Recently Used).

💡 Bí mật của JavaScript Map

Theo chuẩn ECMAScript, Map trong JavaScript luôn bảo toàn thứ tự chèn (Insertion Order). Phương thức map.keys().next().value luôn lấy ra phần tử cũ nhất (đầu map). Bằng cách xóa key và chèn lại map.delete(key); map.set(key, val), ta đưa phần tử đó xuống cuối map (thành Most Recently Used) với chi phí $O(1)$ mà không cần tự cài đặt Doubly Linked List !

JavaScript — Cài đặt LRUCache O(1) 
class LRUCache {
  constructor(capacity) {
    if (capacity <= 0) throw new Error('Capacity must be positive');
    this.capacity = capacity;
    this.cache = new Map();
  }

  // Lấy giá trị & refresh vị trí lên Most Recently Used
  get(key) {
    if (!this.cache.has(key)) return undefined;
    const value = this.cache.get(key);
    this.cache.delete(key);
    this.cache.set(key, value); // Đưa xuống cuối
    return value;
  }

  // Thêm/cập nhật giá trị & loại bỏ phần tử cũ nhất nếu vượt dung lượng
  put(key, value) {
    if (this.cache.has(key)) {
      this.cache.delete(key);
    } else if (this.cache.size >= this.capacity) {
      // Xóa phần tử đầu tiên (cũ nhất / ít dùng nhất)
      const oldestKey = this.cache.keys().next().value;
      this.cache.delete(oldestKey);
    }
    this.cache.set(key, value);
  }

  clear() {
    this.cache.clear();
  }
}

3. So sánh Memoize vs LRU Cache

Tiêu chíMemoize (Function Cache)LRU Cache (Data Structure)
Mục đích Gắn trực tiếp vào hàm để nhớ kết quả theo đối số Cấu trúc lưu trữ Key-Value có chính sách đào thải kích thước cố định
