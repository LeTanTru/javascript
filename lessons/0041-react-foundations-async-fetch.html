1. Pattern chuẩn: Data Fetching trong useEffect

React useEffect yêu cầu callback trả về undefined hoặc một hàm Cleanup function. Do đó bạn không được truyền trực tiếp async () => {} (vì async function luôn trả về Promise):

JavaScript — Clean Async Effect Pattern 
function UserProfile({ userId }) {
  const [user, setUser] = useState(null);
  const [loading, setLoading] = useState(true);
  const [error, setError] = useState(null);

  useEffect(() => {
    const controller = new AbortController(); // 1. Khởi tạo controller

    async function loadUser() {
      setLoading(true);
      setError(null);
      try {
        const res = await fetch(`/api/users/${userId}`, { signal: controller.signal });
        if (!res.ok) throw new Error(`Lỗi tải dữ liệu: HTTP ${res.status}`); // 2. Bắt buộc kiểm tra res.ok
        const data = await res.json();
        setUser(data);
      } catch (err) {
        if (err.name !== 'AbortError') { // 3. Bỏ qua AbortError khi unmount
          setError(err.message);
        }
      } finally {
        setLoading(false);
      }
    }

    loadUser();

    return () => controller.abort(); // 4. Cleanup: Hủy request nếu userId đổi hoặc component unmount
  }, [userId]);
}

2. Bẫy Race Conditions (Xung đột thứ tự phản hồi)

Khi người dùng chuyển nhanh giữa Tab A (User 1) và Tab B (User 2), nếu request User 1 phản hồi chậm hơn User 2, giao diện Tab B sẽ bị dữ liệu cũ của User 1 ghi đè (Race Condition)!

Giải pháp chống Race ConditionCơ chế hoạt độngƯu điểm nổi bật
1. Boolean Flag (ignore = true) Đặt cờ let ignore = false trong effect; hàm cleanup set ignore = true. Khi promise trả về, chỉ set state nếu !ignore. Cực kỳ đơn giản, không cần cấu hình network signal.
2. AbortController (Khuyên dùng) Truyền signal: controller.signal vào fetch(); cleanup gọi controller.abort() để hủy ngay trên tầng Browser Network. Tiết kiệm băng thông, CPU và triệt tiêu hoàn toàn race condition từ gốc.

3. Bẫy kinh điển: fetch() không bao giờ reject trên HTTP 404 hoặc 500

⚠️ Lưu ý sống còn về Fetch API

Khác với thư viện Axios, hàm fetch() của trình duyệt chỉ reject Promise khi có lỗi mạng vật lý (Network Failure) hoặc request bị chặn CORS. Nếu máy chủ trả về HTTP 404 Not Found hoặc HTTP 500 Internal Server Error, fetch() vẫn giải quyết Promise thành công (Resolved)! Bạn bắt buộc phải tự kiểm tra if (!response.ok) throw new Error(...).
