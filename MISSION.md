# Mission: JavaScript Core Mastery for Frontend Interview

## Why
Nắm vững bản chất tầng sâu của JavaScript (Core Runtime, Memory Model, V8 Engine, Event Loop, Prototypal Chain, Async Internals) để tự tin vượt qua các vòng phỏng vấn kỹ thuật Frontend (Senior/Mid-level) tại các công ty công nghệ hàng đầu, đồng thời nâng cao khả năng debug, tối ưu hiệu năng và viết code JavaScript chuẩn mực trong các hệ thống quy mô lớn.

## Success looks like
- Giải thích chính xác, gãy gọn các khái niệm cốt lõi (Execution Context, Scope Chain, Closures, `this`, Prototypal Inheritance, Event Loop, Microtasks/Macrotasks) kèm dẫn chứng từ ECMAScript Specification.
- Vượt qua 100% các câu hỏi phỏng vấn hóc búa về Code Output, Async Ordering, Prototype Mutation, Memory Leaks và Type Coercion.
- Tự tay live-coding cài đặt hoàn chỉnh các Polyfill / Utility functions kinh điển trong 10-15 phút: `Promise`, `Promise.all`, `bind`, `call`, `apply`, `debounce`, `throttle`, `deepClone`, `EventEmitter`, `curry`.
- Phân tích và xử lý thành thạo các vấn đề hiệu năng thực tế trên trình duyệt: Critical Rendering Path, Layout Thrashing, Memory Profiling với Chrome DevTools.
- Trình bày câu trả lời phỏng vấn theo phương pháp Top-Down / STAR mạch lạc, tư duy như một Senior/Lead Engineer.

## Parallel project
Không — tập trung 100% vào sân tập practice/ và các bài toán phỏng vấn live-coding.

## Constraints
- Học bằng tiếng Việt, giải thích sâu bản chất "vì sao" và "đánh đổi", không học vẹt cú pháp.
- Mỗi bài học gói gọn trong 1 file HTML tương tác, có quiz phản hồi ngay lập tức và góc câu hỏi phỏng vấn thực tế.
- Mọi ví dụ code mẫu và bài tập đều được kiểm chứng chạy thực tế trong môi trường thực hành.

## Out of scope
- Cú pháp cơ bản vỡ lòng (vòng lặp `for`, câu lệnh `if/else`, toán tử số học cơ bản).
- Khái niệm riêng của từng framework (React Hooks lifecycle, Vue Reactivity, Angular DI) — tập trung 100% vào nền tảng Vanilla JavaScript Core & Browser APIs độc lập framework.
