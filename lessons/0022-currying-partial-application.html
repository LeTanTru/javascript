1. Pure Functions (Hàm thuần khiết) & Determinism

Một hàm được gọi là Pure Function khi và chỉ khi thỏa mãn đồng thời 2 điều kiện bất di bất dịch :

  1. Tính xác định (Determinism) : Với cùng một tập đối số truyền vào, hàm luôn luôn trả về cùng một kết quả duy nhất.
  2. Không có tác dụng phụ (No Side Effects) : Hàm không làm thay đổi bất kỳ trạng thái nào bên ngoài phạm vi của nó (không mutate tham số, không sửa biến global, không gọi HTTP request hay ghi file/console).
Đặc điểmPure Function ✅Impure Function ❌
Tính đoán trước 100% dự đoán được output từ input Phụ thuộc thời gian, state ngoài (Date.now(), Math.random())
Tác dụng phụ Không làm biến đổi bất kỳ dữ liệu ngoài nào Mutate object/array truyền vào, ghi log, gọi DOM/API
Khả năng Test & Cache Cực kỳ dễ viết Unit Test, an toàn để Memoize Khó mock, không thể cache kết quả an toàn
JavaScript — So sánh Pure vs Impure Function 
// ❌ Impure: Mutate mảng gốc và phụ thuộc biến ngoài
let discount = 0.1;
function applyDiscountImpure(cart) {
  cart.forEach(item => item.price -= item.price * discount); // Mutate!
  return cart;
}

// ✅ Pure: Không mutate cart, trả về mảng mới độc lập
function applyDiscountPure(cart, discountRate) {
  return cart.map(item => ({
    ...item,
    price: item.price * (1 - discountRate)
  }));
}

2. Currying: Biến đổi hàm N-arity thành chuỗi Unary Functions

Currying (đặt theo tên nhà toán học Haskell Curry) là kỹ thuật chuyển đổi một hàm nhận $N$ tham số $f(a, b, c, ...)$ thành một chuỗi các hàm, mỗi hàm chỉ nhận 1 tham số duy nhất : $f(a)(b)(c)...$

💡 Arity là gì ?

Arity là số lượng tham số mà một hàm khai báo nhận vào, được truy xuất thông qua thuộc tính fn.length trong JavaScript (không tính các tham số có giá trị mặc định hoặc rest parameters ...rest).

Cài đặt curry() tổng quát (Tự động tích lũy tham số)

Một hàm curry hiện đại trong JavaScript cho phép người dùng truyền tham số linh hoạt: truyền từng cái curried(1)(2)(3) hoặc truyền nhiều cái một lúc curried(1, 2)(3):

JavaScript — Implementation chuẩn của curry() 
function curry(fn) {
  return function curried(...args) {
    // Nếu đã tích lũy đủ số lượng tham số của fn gốc
    if (args.length >= fn.length) {
      return fn.apply(this, args);
    }
    // Nếu chưa đủ, trả về hàm mới để nhận thêm tham số tiếp theo
    return function (...nextArgs) {
      return curried.apply(this, args.concat(nextArgs));
    }.bind(this); // Bảo toàn this context
  };
}

// Sử dụng:
function multiply3(a, b, c) { return a * b * c; }
const curriedMult = curry(multiply3);

curriedMult(2)(3)(4);    // 24
curriedMult(2, 3)(4);    // 24
curriedMult(2)(3, 4);    // 24
curriedMult(2, 3, 4);    // 24

3. Advanced Curry với Placeholder (_)

Trong các thư viện như Lodash hay Ramda, bạn có thể truyền ký tự giữ chỗ _ để bỏ qua tham số ở vị trí hiện tại và điền nó ở lần gọi sau :

JavaScript — Cài đặt curryWithPlaceholder 
const _ = Symbol('curry_placeholder');

function curryWithPlaceholder(fn) {
  return function curried(...args) {
    const hasPlaceholder = args.slice(0, fn.length).includes(_);
    const effectiveArgs = args.filter(arg => arg !== _);

    if (args.length >= fn.length && !hasPlaceholder && effectiveArgs.length >= fn.length) {
      return fn.apply(this, args.slice(0, fn.length));
    }

    return function (...nextArgs) {
      let nextIndex = 0;
      const combined = args.map(arg =>
        arg === _ && nextIndex < nextArgs.length ? nextArgs[nextIndex++] : arg
      );
      while (nextIndex < nextArgs.length) {
        combined.push(nextArgs[nextIndex++]);
      }
      return curried.apply(this, combined);
    }.bind(this);
  };
}

// Ví dụ định dạng tin nhắn:
const formatMsg = curryWithPlaceholder((type, user, text) => `[${type}] ${user}: ${text}`);
const logToAlice = formatMsg(_, 'Alice', _); // Cố định người nhận Alice

logToAlice('INFO')('Chào buổi sáng'); // "[INFO] Alice: Chào buổi sáng"

4. Partial Application (Áp dụng một phần)

Partial Application là kỹ thuật nhận một hàm có $N$ tham số, cố định trước $K$ tham số ($K < N$), và trả về một hàm mới nhận $N - K$ tham số còn lại trong 1 lần gọi tiếp theo.

Tiêu chíCurryingPartial Application
Bản chất Biến đổi $1$ hàm $N$ tham số thành chuỗi $N$ hàm nhận từng tham số Cố định sẵn một số tham số, trả về hàm nhận hết phần còn lại
Số lần gọi Có thể gọi lồng nhau nhiều lần liên tiếp đến khi đủ: f(a)(b)(c) Thường chỉ gọi qua 2 bước: partial(f, a, b)(c)
Hàm tích hợp sẵn Không có sẵn trong JS chuẩn (phải tự viết hoặc dùng thư viện) Có sẵn thông qua Function.prototype.bind(thisArg, ...presetArgs)
JavaScript — Cài đặt partial() Polyfill 
function partial(fn, ...presetArgs) {
  return function (...laterArgs) {
    return fn.apply(this, presetArgs.concat(laterArgs));
  };
}

// Ứng dụng: Tạo API URL Builder
function buildApiUrl(version, resource, id) {
  return `/api/${version}/${resource}/${id}`;
}

const getV2User = partial(buildApiUrl, 'v2', 'users');
getV2User('42'); // "/api/v2/users/42"

5. Ứng dụng thực chiến trong Frontend & React

  • Tạo Custom Logger / Analytics : Cố định trước App Name, Environment, Log Level rồi truyền hàm con cho các modules sử dụng.
  • Data Transformation Pipelines : Kết hợp hàm curried với Array.prototype.map hoặc filter để tạo phong cách lập trình Point-free thanh lịch : 
    const getProp = curry((prop, obj) => obj[prop]);
const getUserNames = users => users.map(getProp('name'));
  • Event Handlers trong React : Thay vì viết arrow functions inline trong JSX onClick={() => handleDelete(id)}, bạn có thể dùng Currying để tạo hàm handler đóng gói id từ trước : onClick={handleDelete(id)}.
