1. Phân biệt Web Worker vs Service Worker vs Worklet

Tiêu chíWeb Worker (Dedicated Worker)Service Worker (Network Proxy)
Mục đích chính Xử lý tính toán nặng ngầm giải phóng UI Main Thread Proxy mạng ngầm, chặn request (intercept fetch), Offline cache, Push notification
Vòng đời (Lifecycle) Gắn liền với tab hiện tại (đóng tab → worker bị hủy) Độc lập với tab — chạy ngầm ngay cả khi người dùng đóng hết các tab
Quyền truy cập DOM ❌ Không có (không có window, document) ❌ Không có (chỉ có caches, fetch, indexedDB)
Giao tiếp postMessage() với tab tạo ra nó postMessage() hoặc phát broadcast đến tất cả tabs mở cùng domain

2. Web Workers & Cơ chế truyền dữ liệu (Data Transfer)

Khi gửi dữ liệu qua worker.postMessage(data), mặc định JavaScript sử dụng Structured Clone Algorithm (sao chép vùng nhớ sâu, hoàn toàn độc lập).
Với các dữ liệu nhị phân khổng lồ (ArrayBuffer hàng chục MB), bạn có thể dùng Transferable Objects (Zero-Copy) để chuyển quyền sở hữu bộ nhớ với tốc độ $0$ms :

JavaScript — Sử dụng Web Worker với Transferable Objects 
// --- main.js ---
const worker = new Worker('heavy-calc.worker.js');

const buffer = new ArrayBuffer(1024 * 1024 * 32); // 32MB dữ liệu

// Chuyển quyền sở hữu buffer cho Worker (Zero-Copy Transfer)
worker.postMessage({ buffer }, [buffer]);
console.log(buffer.byteLength); // 0 ← buffer ở main thread đã bị giải phóng ngay lập tức!

worker.onmessage = (event) => {
  console.log('Kết quả từ worker:', event.data);
};

3. Service Worker & 3 Chiến lược Caching kinh điển

JavaScript — Cài đặt 3 chiến lược trong sw.js 
// 1. Cache-First (Asset tĩnh: JS/CSS/Fonts/Images)
async function cacheFirst(request) {
  const cached = await caches.match(request);
  if (cached) return cached;
  const response = await fetch(request);
  const cache = await caches.open('v1-static');
  cache.put(request, response.clone());
  return response;
}

// 2. Network-First (Dữ liệu động, ưu tiên mới nhất, rớt mạng fallback về cache)
async function networkFirst(request) {
  try {
    const response = await fetch(request);
    const cache = await caches.open('v1-dynamic');
    cache.put(request, response.clone());
    return response;
  } catch (err) {
    const cached = await caches.match(request);
    if (cached) return cached;
    throw err;
  }
}

// 3. Stale-While-Revalidate (Avatar, Feed: Trả cache cũ 0ms và cập nhật ngầm)
async function staleWhileRevalidate(request) {
  const cached = await caches.match(request);
  const networkFetch = fetch(request).then(async (res) => {
    const cache = await caches.open('v1-swr');
    cache.put(request, res.clone());
    return res;
  });
  return cached || networkFetch;
}
