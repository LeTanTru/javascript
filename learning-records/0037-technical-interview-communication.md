# Kỹ năng giao tiếp trong phỏng vấn kỹ thuật: Phương pháp Top-Down, STAR & Làm chủ buổi phỏng vấn

Người học làm chủ kỹ năng giao tiếp và phản biện kỹ thuật chuẩn Senior/Staff Engineer:

1. **Phương pháp Top-Down (Conclusion First)**:
   - Đưa ra kết luận cốt lõi (TL;DR) trong 10 giây đầu tiên.
   - Trình bày 3 trụ cột luận điểm (3 Pillars: Performance, Maintainability, Standards).
   - Đi sâu vào chi tiết kỹ thuật theo yêu cầu của người phỏng vấn.
2. **Tư duy Trade-offs Matrix**:
   - Chủ động phân tích điểm mạnh, điểm yếu và chi phí đánh đổi (CPU vs RAM vs Complexity vs DX).
   - Ví dụ: Virtual DOM Reconciliation vs Fine-grained Signals, Web Workers vs Main Thread Offloading.
3. **Mô hình STAR định lượng số liệu**:
   - Situation -> Task -> Action -> Result với số liệu đo lường cụ thể (% RAM giảm, ms FCP tăng tốc).
4. **Quy trình 5 bước Live-Coding chuẩn mực**:
   - 1. Clarify Requirements & Edge cases
   - 2. Propose High-level Architecture & Big-O Complexity
   - 3. Implement Modular Code
   - 4. Dry Run with Test Cases
   - 5. Optimize & Discuss Trade-offs
