1. Bảng quy chuẩn V8 Compilation Pipeline

TầngThành phầnĐầu vào → Đầu raCơ chế tối ưu
0 Parser / Scanner JS Source Code → AST Phân tích cú pháp, ném Early SyntaxError
1 Ignition AST → Bytecode Khởi động tức thì (Fast Startup), thu thập Type Feedback Vector
2 Sparkplug & Maglev Bytecode → Baseline Machine Code Tăng tốc trung gian 2x–5x mà không tốn chi phí phân tích sâu
3 TurboFan Hot Bytecode → Optimized Machine Code Speculative Optimization: Tạo mã máy siêu tốc nếu kiểu nhất quán.
Bailout / Deopt nếu kiểu dữ liệu bị thay đổi đột ngột!

2. Ma trận Hidden Classes & Inline Caching (IC)

Hidden Classes (Shapes / Maps)

Bản chất : Ánh xạ object động thành mảng fixed offset trong bộ nhớ C++.

Shape Transition : Xây dựng theo thứ tự gán thuộc tính. Cùng thứ tự → cùng Shape (tiết kiệm RAM & kích hoạt Fast Path).

delete obj.prop: Phá vỡ Shape, hạ cấp Object sang Dictionary Mode (chậm hơn 10x-50x).

3 Cấp độ Inline Caching (IC)

1. Monomorphic (1 Shape) : Tối ưu tối đa $O(1)$ — đọc thẳng Memory Offset ngang tốc độ C++.

2. Polymorphic (2-4 Shapes) : Sinh nhánh switch-case nhỏ để kiểm tra Shape.

3. Megamorphic (> 4 Shapes) : Hủy bỏ IC, tra cứu chậm qua Global Hash Table.

3. V8 Garbage Collection & Weak References

JavaScript — WeakRef & FinalizationRegistry Pattern 
// 1. FinalizationRegistry: Cleanup callback khi object bị thu hồi
const registry = new FinalizationRegistry((heldValue) => {
  console.log(`Cleanup: Object "${heldValue}" đã bị giải phóng`);
});

// 2. WeakRef: Giữ tham chiếu yếu không chặn GC
let cacheObj = { key: 'expensive_data' };
registry.register(cacheObj, cacheObj.key);
const weakRef = new WeakRef(cacheObj);

// 3. Truy xuất an toàn qua deref()
const liveData = weakRef.deref(); // Trả về object hoặc undefined nếu đã bị GC dọn
