Bài 40 · Array Methods & Immutability cho React State (map, filter, reduce & ES2023 Non-mutating Methods)

Làm chủ các thao tác Thêm, Sửa, Xóa và Tính toán trạng thái danh sách trong React mà không vi phạm nguyên tắc Bất biến (State Immutability). Khám phá các phương thức mảng hiện đại ES2023 (toSorted, toReversed, toSpliced, with) và kỹ thuật tính toán Derived State với reduce.

⏳ ~25 phút · 🎯 Mục tiêu: Trở thành chuyên gia xử lý Array State trong React, loại bỏ hoàn toàn các lỗi đột biến mảng (Array Mutation Bugs) và tối ưu hóa re-rendering.

1. Bộ 3 thao tác cơ bản: Thêm, Xóa, Sửa trong React State

Thao tácCách SAI (Mutate mảng cũ)Cách ĐÚNG CHUẨN REACT (Immutable)
1. Thêm (Add) todos.push(newItem) setTodos(prev => [...prev, newItem]) (Thêm cuối)
setTodos(prev => [newItem, ...prev]) (Thêm đầu)
2. Xóa (Delete by ID) todos.splice(index, 1) setTodos(prev => prev.filter(item => item.id !== id))
3. Sửa (Update by ID) todos[index].text = 'Mới' setTodos(prev => prev.map(item => item.id === id ? { ...item, text: 'Mới' } : item))

2. Cuộc cách mạng ES2023: Non-mutating Array Methods

Trước ES2023, các phương thức như sort(), reverse(), splice() đều làm thay đổi trực tiếp mảng gốc (Mutating). Giờ đây chuẩn ECMAScript đã bổ sung bộ 4 phương thức an toàn tuyệt đối cho React State:

JavaScript — ES2023 Non-mutating Methods 
const numbers = [3, 1, 4, 1, 5];

// 1. toSorted: Sắp xếp mảng trả về mảng mới (Không đổi mảng numbers)
const sorted = numbers.toSorted((a, b) => a - b); // [1, 1, 3, 4, 5]

// 2. toReversed: Đảo ngược mảng trả về mảng mới
const reversed = numbers.toReversed(); // [5, 1, 4, 1, 3]

// 3. toSpliced: Chèn/Xóa tại vị trí bất kỳ trả về mảng mới
const inserted = numbers.toSpliced(2, 0, 999); // [3, 1, 999, 4, 1, 5]

// 4. with: Thay thế phần tử tại index chỉ định trả về mảng mới
const updated = numbers.with(0, 100); // [100, 1, 4, 1, 5]

3. Tính toán Derived State với reduce (Tránh lưu thừa State)

Một lỗi phổ biến trong React là tạo thêm useState(total) và cập nhật nó trong useEffect. Thay vào đó, hãy tính toán trực tiếp trong hàm component bằng Derived State:

JavaScript — Derived State Calculation Pattern 
function ShoppingCart({ items }) {
  // ✅ Tính toán trực tiếp trong render body bằng reduce: Không cần useState thừa thãi!
  const totalAmount = items.reduce((sum, item) => sum + item.price * item.quantity, 0);
  const totalItems = items.reduce((sum, item) => sum + item.quantity, 0);

  return (
    <div>
      <h3>Giỏ hàng ({totalItems} món)</h3>
      <p>Tổng thanh toán: ${totalAmount}</p>
    </div>
  );
}
