1. Vấn đề của Dynamic Object & Giải pháp Hidden Class của V8

Trong các ngôn ngữ tĩnh như C++ hoặc Java, vị trí bộ nhớ (Offset) của các trường trong Object được xác định cố định ngay lúc biên dịch. Nhưng trong JavaScript, object là một bảng băm (hash table) động.
Nếu mỗi lần truy xuất point.x, V8 đều phải tra cứu chuỗi "x" trong bảng băm, tốc độ sẽ cực kỳ chậm.

💡 Phát minh Hidden Class (Shape)

V8 ngầm tạo ra các lớp ẩn (Hidden Classes hay Shapes / Maps) trong bộ nhớ C++. Mỗi Shape lưu trữ danh sách tên thuộc tính kèm vị trí Offset tương ứng trong mảng giá trị của Object. Khi nhiều object có cùng thuộc tính theo cùng thứ tự, chúng sẽ dùng chung một Hidden Class duy nhất !

2. Cây chuyển đổi Shape (Shape Transition Tree)

JavaScript — Cùng thứ tự vs Khác thứ tự khởi tạo 
// ✅ TỐT: Cùng thứ tự khởi tạo thuộc tính -> CHIA SẺ CÙNG SHAPE
function Point(x, y) {
  this.x = x; // Chuyển từ Shape C0 → C1 (offset 0: x)
  this.y = y; // Chuyển từ Shape C1 → C2 (offset 1: y)
}
const p1 = new Point(1, 2); // Shape C2
const p2 = new Point(3, 4); // Shape C2 (Tái sử dụng 100%!)

// ❌ XẤU: Khác thứ tự khởi tạo -> RẼ NHÁNH SHAPE MỚI
const a = {}; a.x = 1; a.y = 2; // C0 → C1 → C2
const b = {}; b.y = 2; b.x = 1; // C0 → C3 → C4 (Shape C4 khác C2!)

3. Ba cấp độ của Inline Caching (IC)

Tại mỗi điểm truy xuất thuộc tính trong code (Call Site như obj.x), V8 ghi nhớ (cache) lại Shape và Offset của các object truyền qua đó :

Cấp độ ICSố lượng Shapes đã thấyHiệu năngCơ chế V8
Monomorphic 🏆 Đúng 1 Shape duy nhất Cực nhanh ($O(1)$) — ngang C++ Ghi trực tiếp mã máy đọc thẳng tại Memory Offset
Polymorphic ⚠ Từ 2 đến 4 Shapes Nhanh (có điều kiện) Sinh chuỗi switch-case nhỏ để kiểm tra Shape
Megamorphic ❌ Trên 4 Shapes (> 4) Chậm nhất ($O(N)$) Từ bỏ Inline Cache, tra cứu qua Global Stub / Hash Table

4. Tác hại chết người của toán tử delete obj.prop

⚠ delete biến Fast Properties thành Dictionary Mode

Khi bạn gọi delete obj.prop, V8 không thể tạo Shape chuyển tiếp ngược lại một cách hiệu quả. Do đó, V8 sẽ hạ cấp Object từ Fast Mode (dùng Shape) sang Slow Mode / Dictionary Mode (dùng HashMap thuần), khiến mọi thao tác đọc ghi trên object đó bị chậm đi gấp 10 đến 50 lần !
Giải pháp chuẩn Senior : Thay vì delete obj.temp, hãy gán obj.temp = undefined hoặc null.
