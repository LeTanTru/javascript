Tổng hợp kiến thức Module 04 : This, Arrow Functions & Function Internals

Bản đồ tư duy tóm lược cô đọng toàn bộ kiến thức chuyên sâu từ Bài 13 đến Bài 15 — Sẵn sàng cho mọi câu hỏi phỏng vấn hóc búa về context, Lexical scope và live-coding polyfills.

1. Trục 1: 4 Quy tắc xác định `this` & Thứ tự ưu tiên (Bài 13)

Thứ tự ưu tiên Quy tắc Cú pháp gọi hàm Giá trị của `this`
1 (Cao nhất) New Binding new MyConstructor() Đối tượng instance mới được tạo và liên kết prototype chain.
2 Explicit / Hard Binding fn.call(ctx), fn.apply(ctx), fn.bind(ctx) Chính xác đối tượng ctx được chỉ định. Lưu ý: new ghi đè được bind !
3 Implicit Binding contextObj.method() Đối tượng nằm ngay trước dấu chấm tại thời điểm gọi (call-site). Nguy cơ: Implicit Loss khi truyền callback.
4 (Thấp nhất) Default Binding standaloneFunction() Non-strict mode: window (browser) / global (Node.js).
Strict mode: undefined.

2. Trục 2: Arrow Functions & Lexical `this` (Bài 14)

Đặc tính Cơ chế kỹ thuật Hệ quả thực tế
Lexical this Không có internal slot this. Tra cứu this như một biến thông thường qua Scope Chain từ môi trường ngoài. Miễn nhiễm tuyệt đối với call(), apply(), bind(). Không bao giờ bị mất context trong async callbacks.
Không có arguments Engine không khởi tạo Arguments Object cho Arrow Function Execution Context. Nếu truy cập arguments sẽ lấy nhầm của hàm cha bên ngoài. Thay thế bằng ...rest parameters.
Không có prototype & new Không sở hữu internal method [[Construct]], không được Engine cấp phát thuộc tính prototype (bằng undefined). Tiết kiệm bộ nhớ RAM đáng kể; ném TypeError: ... is not a constructor nếu gọi với từ khóa new.

3. Trục 3: Ma trận so sánh Regular Function vs Arrow Function

Tiêu chí Regular Function (Declaration / Expression) Arrow Function (() => {})
Ràng buộc `this` Động (Dynamic) theo call-site tại runtime Tĩnh (Lexical) theo định nghĩa từ vựng
Biến `arguments` Có sẵn Arguments Array-like Không có (dùng ...rest)
Gọi với toán tử `new` Hợp lệ (nếu không phải method shorthand) Bị cấm (TypeError)
Thuộc tính `prototype` Có (mặc định là { constructor: fn }) undefined
Dùng làm Object Method Khuyên dùng (truy cập được this.prop) Bẫy chết người (this trỏ ra Global)
Dùng trong Async Callbacks Dễ bị Implicit Loss (phải bind hoặc self=this) Hoàn hảo (tự bảo toàn context cha)

4. Trục 4: Bộ 3 Polyfills chuẩn Senior (Bài 15)

JavaScript — Cẩm nang Polyfill myCall, myApply, myBind 
// 1. Polyfill myCall
Function.prototype.myCall = function (context, ...args) {
  if (context === null || context === undefined) context = globalThis;
  else context = Object(context);

  const fnKey = Symbol('fnKey'); // Property Hijacking
  context[fnKey] = this;
  const result = context[fnKey](...args);
  delete context[fnKey];
  return result;
};

// 2. Polyfill myApply
Function.prototype.myApply = function (context, argsArray) {
  if (context === null || context === undefined) context = globalThis;
  else context = Object(context);

  const fnKey = Symbol('fnKey');
  context[fnKey] = this;
  const result = (!argsArray || !Array.isArray(argsArray)) ? context[fnKey]() : context[fnKey](...argsArray);
  delete context[fnKey];
  return result;
};

// 3. Polyfill myBind (Hỗ trợ Currying & new keyword override)
Function.prototype.myBind = function (context, ...bindArgs) {
  const originalFn = this;
  if (typeof originalFn !== 'function') throw new TypeError('Invalid callable');

  function boundFn(...callArgs) {
    const isNewInstance = this instanceof boundFn;
    const targetContext = isNewInstance ? this : (context ?? globalThis);
    return originalFn.apply(targetContext, [...bindArgs, ...callArgs]);
  }

  if (originalFn.prototype) boundFn.prototype = Object.create(originalFn.prototype);
  return boundFn;
};
