1. Bảng tra cứu 8 Bẫy Code Output kinh điển trong phỏng vấn

Chủ đề bẫyCạm bẫy thường gặpBản chất theo chuẩn ECMA-262
1. Function Hoisting in Blocks var a = 1; function test() { a = 10; return; function a() {} } Hàm function a() {} hoist lên đầu scope hàm test tạo local variable a. Phép gán không ảnh hưởng global a.
2. Sparse Array Holes [1, , 3].map(x => x * 2) Các phương thức lặp (map, forEach, filter) tự động bỏ qua empty holes; 2 in arr trả về false.
3. Object Property Keys Order Thứ tự in ra của Object.keys({ '2': 'b', '1': 'a', 'z': 'c' }) Duyệt theo thứ tự: Số nguyên dương tăng dần ("1", "2") → Chuỗi ký tự theo thứ tự chèn → Symbols.
4. Symbol.toPrimitive Priority Object ép kiểu ngầm định khi +, ==, ${} Thứ tự ưu tiên: Symbol.toPrimitive(hint) > valueOf() > toString().
5. Constructor Return Override function Foo() { return { custom: true }; } Nếu constructor return Object, new Foo() trả về object đó và phá vỡ instanceof Foo. Nếu return Primitive thì bị bỏ qua.
6. Proxy Invariant Protection Proxy cố tình trả về giá trị khác cho non-writable & non-configurable property JavaScript runtime tự động ném TypeError để bảo vệ tính toàn vẹn bộ nhớ (Invariant violation).
7. Microtask Starvation Đệ quy Promise.resolve().then(recurse) Microtask queue không bao giờ cạn, chiếm trọn Call Stack và làm đói (starve) Macrotask timers & UI render.
8. Class Private Fields (#) Cố gắng truy xuất obj.#privateProp từ bên ngoài hoặc qua Object.keys Hard Privacy: Không thể truy xuất qua bất kỳ reflection API nào (kể cả getOwnPropertySymbols).

2. 3 Bài toán Live-Coding phân loại Senior / Lead

1. Priority Async Scheduler

Quản lý hàng đợi async tasks với giới hạn concurrency và sắp xếp ưu tiên theo priority giảm dần. Giải phóng slot an toàn bằng try/finally.

2. Deep Object Diff & Patch

Thuật toán so sánh đệ quy phát hiện biến động cấu trúc { added, updated, deleted } và hàm applyPatch khôi phục state bất biến.

3. Fine-Grained Reactive Signal

Tự động thu thập dependencies trong read() qua activeEffect và thông báo lại toàn bộ subscribers (Set) trong write().

3. Khung giao tiếp phỏng vấn Top-Down & STAR

Top-Down (Conclusion First)

  1. TL;DR Upfront: Kết luận chính trong 1 câu.
  2. 3 Pillars: 3 luận điểm cốt lõi (Hiệu năng, Bộ nhớ, Tính duy trì).
  3. Deep Dive: Phân tích chi tiết khi được hỏi.

Mô hình STAR có số liệu

  • S - Situation: Bối cảnh sự cố cụ thể.
  • T - Task: Nhiệm vụ và mục tiêu cần đạt.
  • A - Action: Hành động kỹ thuật chính xác.
  • R - Result: Kết quả đo lường (% RAM, ms FCP).
