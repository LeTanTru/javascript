# JavaScript Core for Frontend Interview Resources

## Knowledge (Nguồn chuẩn & Tài liệu chính thức)

- [ECMAScript® 2026 Language Specification (ECMA-262)](https://tc39.es/ecma262/)
  Tài liệu đặc tả chuẩn xác nhất của ngôn ngữ JavaScript. Dùng để tra cứu: cơ chế Type Coercion (`ToPrimitive`, `ToNumber`), thuật toán so sánh trừu tượng, mô hình bộ nhớ, `Promise.withResolvers`, `WeakRef`, và đặc tả Event Loop/Job Queues.
- [MDN Web Docs — JavaScript Reference](https://developer.mozilla.org/en-US/docs/Web/JavaScript)
  Nguồn tài liệu thực tế chuẩn mực cho Web Developers. Dùng để tra cứu: API cú pháp, `AbortController`, `Proxy` & `Reflect`, `structuredClone`, `WeakMap`/`WeakRef`, trình duyệt tương thích.
- [V8 Engine Blog & Documentation](https://v8.dev/blog)
  Blog chính thức của đội ngũ kỹ sư Google V8. Dùng để tra cứu: cơ chế JIT Compilation (Ignition & TurboFan), Hidden Classes, Inline Caching, Garbage Collection (Orinoco, Scavenger, Mark-Sweep-Compact).
- [You Don't Know JS Yet (2nd Edition) — Kyle Simpson](https://github.com/getify/You-Dont-Know-JS)
  Bộ sách kinh điển đào sâu cơ chế ngôn ngữ: Scopes & Closures, Objects & Classes, Types & Grammar.
- [JavaScript.info — The Modern JavaScript Tutorial](https://javascript.info/)
  Khóa học toàn diện và sâu sắc từ cơ bản đến nâng cao: Event Loop, Microtasks, DOM manipulation, Prototypal inheritance, Network cancellation.
- [web.dev — Performance & Rendering](https://web.dev/)
  Nguồn chính thống của Google về hiệu năng Web: Critical Rendering Path, Layout Thrashing, Core Web Vitals (LCP, INP, CLS).
- [Jake Archibald: In The Loop (JSConf)](https://www.youtube.com/watch?v=cCOL7MC4Pl0)
  Bài thuyết trình kinh điển về cơ chế Event Loop trên trình duyệt, render pipeline, microtasks vs macrotasks vs `requestAnimationFrame`.

## Wisdom (Cộng đồng & Luyện phỏng vấn thực chiến)

- [GreatFrontEnd (Frontend Interview Prep)](https://www.greatfrontend.com/)
  Nền tảng luyện phỏng vấn Frontend chuẩn hóa hàng đầu hiện nay bởi các cựu Tech Lead FAANG: 50+ Must-know JS questions, JS utility coding problems (`debounce`, `flatten`, `deepClone`, `EventEmitter`, `p-limit`).
- [BigFrontend.dev (BFE.dev)](https://bigfrontend.dev/)
  Sân luyện code JavaScript Polyfills, Type quiz, Async queues và DOM coding phỏng vấn từ Meta, Google, Amazon, ByteDance.
- [r/javascript & r/Frontend](https://reddit.com/r/javascript)
  Cộng đồng thảo luận kỹ thuật quốc tế, chia sẻ kinh nghiệm phỏng vấn và các case study thực tế.
